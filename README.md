# 폴드책 (fold-book)

갤럭시 폴더블에서 쓰는 책 뷰어. 이미지 폴더를 종이책처럼 넘겨 본다.
로컬 저장소 · 윈도우 공유폴더(SMB) · 구글 드라이브를 지원. 패키지: `com.foldbook`

## 빌드
```
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot
gradlew :app:assembleDebug          # 또는 installDebug (연결된 기기)
gradlew :app:testDebugUnitTest
```
AGP 8.7.3 / Kotlin 2.1.0 / Gradle 8.14.3 / compileSdk 35 / minSdk 26.
(저메모리 환경에서는 `gradle.properties` 의 힙을 낮추고 `org.gradle.daemon=false` 로 빌드)

## UI 구조 (Jetpack Compose + Material 3)
하단 네비게이션 **홈 / 탐색 / 설정**. 탭·화면 전환은 방향이 보이는 가로 슬라이드.

- **홈** — 두 그룹으로 표시.
  - **이어보기**: 아직 안 끝난 세션. 누르면 마지막 본 페이지부터. 길게 누르면 **완료 목록으로 이동 / 삭제** 선택.
  - **완료**: 폴더 끝까지 다 본 세션. 그룹 헤더의 🗑 버튼으로 일괄 삭제. 누르면 처음부터 다시 보기.
  세션은 그 폴더의 마지막 파일까지 보면 '완료' 로 이동하고, **바로 위 부모가 같은** 다음 폴더가 있으면
  그 세션이 자동으로 시작된다(예: `원피스/1권` → `원피스/2권`). 없으면 '마지막 권' 알림만 뜬다.
  완료로 넘어간 세션의 미리불러오기 캐시는 그때 정리된다.
  홈에 구글 드라이브 세션/연결이 있으면 앱 시작 시 백그라운드로 드라이브 액세스 토큰을 미리 받아 둔다
  (첫 파일 열 때 로딩 단축).
- **탐색** — 저장소 연결 목록. `기기 저장소` 기본 제공. `+` 로 SMB / 구글 드라이브 추가.
  같은 종류 여러 개 가능(공유폴더 여러 경로, 드라이브 여러 계정).
  연결을 길게 누르거나 진입 후 `⋮` → **별칭 변경 / 삭제 / 다운로드**.
  폴더 탐색 화면:
  - **현재 전체 경로**를 제목 아래에 표시 (로컬=실경로, SMB=`smb://host/share/...`, 드라이브=이름 경로)
  - 하위폴더 + **이미지 썸네일** 함께 표시 (원격 썸네일은 설정에서 끌 수 있음)
  - 폴더 선택 → 첫 이미지부터 / 이미지 선택 → 그 이미지부터 (예: 5/10)
  - `⋮ → 다운로드` → 파일·폴더 체크 선택 → 저장 위치(폴더) 지정 → 로컬로 복사(폴더 재귀)
- **설정** — 각 옵션마다 상세 설명. 읽기 방향 **기본값**(책마다 뷰어 설정에서 따로 변경 가능) /
  페이지 표시(자동·한 장·양면) / 양면 스캔본 분할 토글 /
  원격 분할 분석 토글 / 미리 불러올 장 수(1~12) / 원격 썸네일 토글 / 폴더블 접힘 토글 /
  **현재 버전 + 업데이트 확인**(GitHub 최신 릴리즈와 비교, 새 버전이면 주황색으로 표시·클릭 시 릴리즈 페이지).

## 리더
- 드래그 위치를 따라오는 3D 종이책 페이지 넘김 (`eschao/android-PageFlip`, `pageflip/` 로 벤더링).
  - 드래그 중엔 자동으로 안 넘어가고, **손을 뗀 위치가 화면 절반을 지났으면** 완료(아니면 되돌림).
  - 화면 **한쪽 끝에서 반대쪽 끝까지** 드래그해도 모서리 컬이 끊기지 않고 이어진다
    (`PageFlip.java` 가 과도 드래그를 가장자리에 고정).
  - **일본 만화(우→좌)** 모드에선 뷰를 좌우로 뒤집어(`scaleX=-1`) **왼쪽→오른쪽 드래그로 다음 페이지(다음 이미지)** 로
    넘어가고 컬도 손가락을 따라간다. 뒤집힌 화면에서 글자가 정방향이 되도록 텍스처만 그릴 때 반전한다
    (원본 파일은 그대로). 양면 스캔본은 오른쪽 절반부터 읽는다.
  - **첫 페이지에서 뒤로** 넘기면 "첫 페이지입니다 · 이전 권으로 이동할까요?" 를 묻고, 첫 권이면 못 간다고 알린다.
- **화면을 한 번 탭하면 오버레이 표시**: 상단에 뒤로가기·제목·뷰어설정 버튼, 하단에 `현재/전체` 페이지
  표시와 **가로 스크러버**(끌어서 어느 페이지로든 점프, RTL 은 오른쪽이 1페이지). 뷰어설정에서
  두 쪽 보기/**이 책의 읽기 방향**을 그 자리에서 바꿀 수 있음(변경 시 현재 페이지에서 다시 로드).
- **창(window) 방식 로딩**: 파일 목록만 먼저 읽고, **현재 페이지를 최우선으로** 받아 디코드한 뒤에야
  앞뒤 몇 장을 가까운 순으로 미리 받는다. 아직 안 받은 페이지는 **회색**으로 보이다 도착 시 교체.
  미리 불러올 장 수는 설정에서 조절(1~12).
- 받은 파일은 세션 캐시(`cacheDir/sessions/<id>/`), **세션 종료/삭제 시 삭제** + 시작 시 찌꺼기 정리 + 400MB 상한.
- **좌우 양면 스캔본**(가로가 긴 이미지)은 좌/우로 분할 →
  한 쪽씩 볼 땐 반씩(폴드 접은 세로 화면 포함), **양면 모드에선 두 절반이 한 화면**(정렬용 빈 페이지 자동 삽입).
  설정에서 분할을 끄면 통짜 표시.
- **원격(SMB/드라이브)도 분할 지원**: 파일 헤더(앞 64KB)만 받아 `ImageHeader` 로 크기 파싱 →
  스캔본 여부 판정. 폴더 열 때 병렬로 분석(진행 중 스피너), 결과는 프로세스 동안 캐시.
- **폴드/펼침·회전으로 해상도가 바뀌어도 Activity 를 재생성하지 않고**(`configChanges`) 그 자리에서
  표면만 다시 잡아 대응 — 튕김 없이, 세션·캐시·현재 페이지 유지. GL 그리기도 예외를 삼켜 재구성 중 죽지 않는다.
- 갤럭시 폴드: 살짝 접었다 펴면 다음 페이지 (`androidx.window`, 설정 토글).

## 검증 상태
- `assembleDebug` / `assembleRelease` / 단위 테스트(자연 정렬 · SpreadPolicy · ImageHeader) **통과**.
- 이 PC는 RAM 부족으로 에뮬레이터 구동 불가 → **실기기에서 `installDebug` 로 실제 동작 확인 필요.**
- 다운로드 기능은 화면을 벗어나면(다른 탭 이동 등) 중단됨 — 완료까지 화면 유지 권장.
