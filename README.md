# 폴드책 (fold-book)

갤럭시 폴더블에서 쓰는 책 뷰어. 이미지 폴더를 종이책처럼 넘겨 본다.
로컬 저장소 · 윈도우 공유폴더(SMB) · 구글 드라이브를 지원. 패키지: `com.foldbook`

## 빌드
```
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot
gradlew :app:assembleDebug          # 또는 installDebug (연결된 기기)
gradlew :app:testDebugUnitTest
```
AGP 8.7.3 / Kotlin 2.1.0 / Gradle 8.14.3 / compileSdk 35 / minSdk 26.
(저메모리 환경에서는 `gradle.properties` 의 힙을 낮추고 `org.gradle.daemon=false` 로 빌드)

## UI 구조 (Jetpack Compose + Material 3)
하단 네비게이션 **홈 / 탐색 / 설정**. 탭·화면 전환은 방향이 보이는 가로 슬라이드.
색은 시스템 벽지색(dynamic color) 대신 **브랜드 인디고**로 고정(`ui/Theme.kt`, 라이트/다크 전용 스킴).
상단바는 가운데 정렬, 홈의 세션은 둥근 ElevatedCard + 아이콘 칩.

- **홈** — 두 그룹으로 표시.
  - **이어보기**: 아직 안 끝난 세션. 누르면 마지막 본 페이지부터. 길게 누르면 **완료 목록으로 이동 / 삭제** 선택.
  - **완료**: 폴더 끝까지 다 본 세션. 그룹 헤더의 🗑 버튼으로 일괄 삭제. 누르면 처음부터 다시 보기.
  세션은 그 폴더의 마지막 파일까지 보면 '완료' 로 이동하고, **바로 위 부모가 같은** 다음 폴더가 있으면
  그 세션이 자동으로 시작된다(예: `원피스/1권` → `원피스/2권`). 없으면 '마지막 권' 알림만 뜬다.
  완료로 넘어간 세션의 미리불러오기 캐시는 그때 정리된다.
  홈에 구글 드라이브 세션/연결이 있으면 앱 시작 시 백그라운드로 드라이브 액세스 토큰을 미리 받아 둔다
  (첫 파일 열 때 로딩 단축).
- **탐색** — 저장소 연결 목록. `기기 저장소` 기본 제공. `+` 로 SMB / 구글 드라이브 추가.
  같은 종류 여러 개 가능(공유폴더 여러 경로, 드라이브 여러 계정).
  연결을 길게 누르거나 진입 후 `⋮` → **별칭 변경 / 삭제 / 다운로드**.
  폴더 탐색 화면:
  - **현재 전체 경로**를 제목 아래에 표시 (로컬=실경로, SMB=`smb://host/share/...`, 드라이브=이름 경로)
  - 하위폴더 + **이미지 썸네일** 함께 표시 (원격 썸네일은 설정에서 끌 수 있음)
  - 폴더 선택 → 첫 이미지부터 / 이미지 선택 → 그 이미지부터 (예: 5/10)
  - (로컬만) `⋮ → 갤러리에서 숨기기 (.nomedia)` 로 현재 폴더에 `.nomedia` 생성/삭제, 하위 폴더는 **길게 눌러** 토글.
    `.nomedia` 인 폴더는 목록에 눈 감은 아이콘 + "갤러리에서 숨김" 표시. 토글 후 해당 폴더를 재스캔.
  - `⋮ → 다운로드` → 파일·폴더 체크 선택 → 저장 위치(폴더) 지정 → **포그라운드 서비스(`DownloadService`)** 가
    폴더 재귀로 로컬 복사. 알림에 진행률 표시(취소 액션 포함), 화면을 벗어나거나 잠겨도 계속되며, 앱이 떠 있는
    동안엔 화면이 꺼지지 않는다. **탐색 탭 상단·폴더 화면 하단에 `DownloadCard`** 로 진행/현재 파일/취소 표시.
    알림을 탭하면 앱이 열리며 탐색 탭으로 이동. 같은 이름의 파일이 이미 있으면 **덮어쓰기/건너뛰기(이후 모두 적용)** 를 물어본다.
- **설정** — 각 옵션마다 상세 설명. 읽기 방향 **기본값**(책마다 뷰어 설정에서 따로 변경 가능) /
  페이지 표시(자동·한 장·양면) / 양면 스캔본 분할 토글 / 원격 분할 분석 토글 / 미리 불러올 장 수(1~12) /
  **터치 넘김 가장자리 영역**(펼침·접힘 각각 0~50%) / 원격 썸네일 토글 / 폴더블 접힘 토글 /
  **현재 버전 + 업데이트 확인**(GitHub 최신 릴리즈와 비교, 새 버전이면 주황색으로 표시·클릭 시 릴리즈 페이지).

## 리더

- **드래그를 따라오는 3D 종이 컬** — `eschao/android-PageFlip` 을 `pageflip/` 로 벤더링해서 쓴다
  (`PageFlipView` / `PageRender`). **손을 뗄 때까지 손가락을 따라간다** — 화면 중앙이나 반대쪽 페이지
  위까지 끌고 갈 수 있고, 손 뗀 위치가 페이지 절반을 지났으면 넘어가고 아니면 제자리로 되돌아간다.
- **읽기 방향(RTL, 일본 만화)은 넘김 효과를 좌우로 뒤집지 않는다.** `PageImageProvider` 가 라이브러리
  페이지 순번을 읽기 순번의 **역순으로 매핑**할 뿐이다 → eschao 는 LTR 그대로 그리고, "왼쪽→오른쪽 드래그"
  가 읽기상 **다음** 파일을, "오른쪽→왼쪽 드래그"가 **이전** 파일을 불러온다.
  이미지도 스프레드 스캔본도 절대 반전하지 않는다.
- **어느 쪽으로 끌든 "현재 페이지가 접히면서 넘어갈 페이지가 드러난다".** 벤더링한 라이브러리를 고쳐
  왼쪽 가장자리를 기준점으로 삼는 접힘도 forward flip 으로 처리한다(`PageFlip.setOriginAndDiagonalPoints`
  호출부 + `isOriginAtLeft()`). 원본의 backward flip(= 넘어갈 페이지가 펼쳐지는 효과)은 쓰지 않는다.
- **넘김 애니메이션 도중에도 계속 넘길 수 있다.** 넘김 중에 끌거나 가장자리를 탭하면 진행 중인 넘김을
  그 자리에서 확정(`PageRender.settleNow`)하고 새 넘김을 시작한다. 그냥 화면을 건드린 것만으로는
  애니메이션이 끊기지 않게, 실제로 끌거나 탭으로 확정될 때까지 잡기를 미룬다.
- **가장자리 탭 넘김은 합성 드래그**로 처리한다. 실제 책처럼 아래 모서리를 잡고 대각선 위로 휙 채듯이
  `SYNTH_DRAG_MS` 동안 가속하며 페이지 절반을 넘긴 뒤, 그 속도를 `PageFlip.onFingerUp(…, velocityX)` 로
  넘겨 감속 스크롤러가 이어받는다(속도가 0 으로 떨어지지 않아 중간에 멈칫하지 않음). 손가락 드래그의
  놓기는 기존 스크롤러 그대로.
- **양면 모드에서 스파인을 넘어서는 오버드래그**도 손가락을 따라간다. 접힘선이 페이지 밖으로 나가면
  스파인을 축으로 계속 회전시킨다(`PageFlip.limitFoldXInDoublePage`, 애니메이션과 드래그 공용).
- 단면(폴드 접힘) 모드에선 접힘 뒷면을 어둡게 처리해, 반대 방향으로 넘길 때 다음 페이지 내용이 뒷면에 비치지 않는다.
- **첫 페이지에서 뒤로** 넘기면 "이전 권으로 이동할까요?" (첫 권이면 안내만). **마지막에서 앞으로**도
  "‘다음 폴더명’ 으로 이동할까요?" 를 물어본 뒤 이동한다(예: `원피스/1권`→`원피스/2권`).
  다음 권이 없으면 "마지막 권" 알림만.
- **화면 탭**: 가운데를 누르면 오버레이 — 위/아래 그라데이션 위에 뜨는 둥근 유리판 바(상단 뒤로가기·제목·
  뷰어설정, 하단 `현재/전체` 알약 칩 + **가로 스크러버**, 스크럽 중에는 끌고 있는 페이지 번호를 미리 표시),
  **좌·우 가장자리 영역**을 누르면 페이지 넘김. 가장자리 영역 너비는 설정에서 조절하며 **폴드 펼침/접힘을 따로 저장**한다.
  뷰어설정에서 두 쪽 보기 / **이 책의 읽기 방향** / **이 책의 스캔 보정**을 즉시 변경.
- **창(window) 방식 로딩**(`reader/PageSource`): 현재 페이지를 최우선으로 디코드한 뒤에야 앞뒤 몇 장을
  가까운 순으로 미리 받는다. 미준비 페이지는 회색, 도착 시 교체. 장 수는 설정에서 1~12.
- **이미지 맞춤 방식**(설정, `FitMode`): 전부 보이기(기본·잘림 없음) / 가로 맞춤(위아래 잘림) /
  세로 맞춤(좌우 잘림). `PageSource.decode` 의 배율 계산에만 관여하고, 넘쳐서 잘릴 때는 가운데를 보여준다.
- **양면 모드의 여백은 바깥쪽에만**: 이미지가 페이지보다 좁으면 가운데(책등) 쪽에 딱 붙이고 남는 여백을
  화면 좌·우 끝으로 보낸다. 왼쪽 슬롯 = 라이브러리 홀수 페이지라는 규칙(`spreadAlignX`, 단위테스트 있음)을
  `PageImageProvider.setSpread` → `PageSource.setAlign` 으로 전달하고, 정렬이 바뀌면 다시 디코드한다.
- **스캔 보정**(뷰어 설정, 이 책만 / `Session.enhanceScan`): 가로줄 48개를 훑어 밝기 히스토그램을 만들고
  3%~92% 구간을 0~255 로 펴는 ColorMatrix 를 그릴 때 적용한다(회색조 + 레벨 보정). 흐린 흑백 스캔본의
  잿빛 배경이 하얘지고 흐린 선이 진해진다. 픽셀 복사가 없어 메모리 비용이 없다.
- **이어보기 즉시 열기**(`reader/SessionManifest`): 세션 캐시에 이미지 목록·스캔본 크기를 `manifest.json` 으로
  저장해, 앱을 껐다 켠 뒤에도 **네트워크 조회 없이** 바로 리더로 진입하고 백그라운드에서 목록을 대조한다.
- 받은 파일은 세션 캐시(`cacheDir/sessions/<id>/`, 파일명 = entryId 해시), 세션 종료/삭제 시 삭제 + 시작 시
  찌꺼기 정리 + 400MB 상한.
- **좌우 양면 스캔본**은 헤더(앞 64KB, `ImageHeader`)로 크기를 파싱해 좌/우로 분할(로컬·원격 모두). 설정에서 끄면 통짜.
- **폴드/펼침·회전**은 `configChanges` 로 Activity 재생성 없이, `PageFlipView.onConfigChanged` 가 표면만 다시
  잡아 단면↔양면까지 전환. `onDrawFrame` 은 재구성 중 예외를 삼킨다.
- 구글 드라이브는 앱 시작 시 백그라운드로 토큰 + 최근 세션 폴더 목록을 미리 데워 첫 로딩을 줄인다.
- 갤럭시 폴드: 살짝 접었다 펴면 다음 페이지 (`androidx.window`, 설정 토글).

## 검증 상태
- `assembleDebug` / `assembleRelease` / 단위 테스트(SessionManifest · 자연 정렬 · SpreadPolicy · ImageHeader) **통과**.
- 이 PC는 RAM 부족으로 에뮬레이터 구동 불가 → **실기기에서 `installDebug` 로 실제 동작 확인 필요.**
  특히 RTL 넘김(효과 반전 없이 순번만 역순)·양면·폴드 전환·홈 복귀는 기기 확인 필요.
- 앱 아이콘은 런처가 캐시하므로 **기존 앱 삭제 후 재설치**해야 새 아이콘이 보인다.
- 다운로드 기능은 화면을 벗어나면(다른 탭 이동 등) 중단됨 — 완료까지 화면 유지 권장.
